# Hydronos - 清爽简洁的博客平台

一个基于 Jekyll 构建的静态博客网站，采用浅蓝色主题、毛玻璃效果和流畅动画设计。

## 特点

- 🌊 **清新设计** - 浅蓝色主题搭配毛玻璃效果
- ⚡ **流畅动画** - 丝滑的过渡动画
- 📱 **响应式布局** - 完美适配各种设备
- 🚀 **快速加载** - 纯静态站点，极速访问

## 本地预览

```bash
# 安装依赖
bundle install

# 启动本地服务器
bundle exec jekyll serve

# 访问 http://localhost:4000
```

## 部署到 GitHub Pages

1. Fork 或克隆此仓库
2. 将仓库重命名为 `yourusername.github.io`
3. 推送到主分支：
   ```bash
   git push origin main
   ```
4. 在 GitHub 仓库设置中启用 GitHub Pages

## 自定义

编辑 `_config.yml` 文件可以修改网站标题、描述、作者信息等。

## 技术栈

- Jekyll 4.x
- CSS3 (毛玻璃效果 + 动画)
- GitHub Pages
